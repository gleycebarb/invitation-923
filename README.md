# 🎓 Convite de Formatura — Padrinho

Este projeto foi criado com muito carinho para realizar um convite especial: **chamar alguém muito importante para ser padrinho(a) de formatura**.  
A ideia é transformar o momento em algo único, memorável e cheio de significado.

---

## ✨ Objetivo

O objetivo deste projeto é apresentar, de forma elegante e personalizada, uma mensagem especial para uma pessoa que marcou uma trajetória.  
O convite expressa gratidão, reconhecimento e admiração — valores fundamentais para escolher um padrinho de formatura.

---

## 💛 Sobre o Projeto

- Desenvolvido com foco em **delicadeza**, **minimalismo** e **afetividade**
  - A trajetória dos formandos com o padrinho
  - A importância da pessoa convidada
  - O pedido oficial de apadrinhamento
